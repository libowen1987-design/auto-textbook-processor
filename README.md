# 📚 电磁神教 — 经典教材数字化图书馆

**27本经典电磁学教材的全套数字化学习资源**

本项目将经典电磁学与微波技术教材逐章清洗、洗稿、代码复现，产出结构化的中英双语学习笔记和完整可运行的 Python 复现代码。

---

## 📂 项目结构

```
.
├── study_notes/          ← 全部教材资源（按书名分目录）
│   ├── {book_name}/     
│   │   ├── notes/        .md 中英双语笔记
│   │   ├── code/         .py 例题复现代码
│   │   └── figures/      .png 科学图表
│   └── ...
├── assets/               ← 项目资产（赞助二维码等）
├── README.md
└── LICENSE
```
